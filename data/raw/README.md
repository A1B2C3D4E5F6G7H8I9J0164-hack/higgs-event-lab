
# Raw Data

Download the official UCI HIGGS dataset locally into this folder. The raw data are **not committed**.

## Requirements & Guidelines

* **Documentation:** Record the source URL, retrieval date, archive/file name, checksum (if feasible), dataset schema, and citation in a data card.
* **Source Integrity:** Do not silently replace the source with a mirror.
