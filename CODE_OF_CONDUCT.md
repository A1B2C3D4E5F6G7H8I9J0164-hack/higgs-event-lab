# Team Code of Conduct

We will communicate respectfully, review work on its merits, give credit for contributions, raise blockers early and make project decisions visible. Disagreement about a technical decision should be documented with evidence and a proposed alternative, not personal criticism.

No team member should be expected to work around-the-clock to compensate for another person's lack of communication. If a task is blocked, tell the team, update the issue and renegotiate scope early.
