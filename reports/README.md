# Reports and figures

The final report is synthesized by Krishna from actual results; each module owner writes the methods/results for their experiments; Saumya reviews readability, references, terminology and consistency. Store report source and selected small figures here. Put large run outputs under the ignored `outputs/` folder and copy only chosen, appropriately sized figures into the report folder when needed.

Report sections: abstract, physics motivation, task, data/provenance, methods, experiment protocol, results, error/threshold analysis, compute trade-off, limitations, conclusion and references. Never write numeric results until they exist in saved experiment output.
