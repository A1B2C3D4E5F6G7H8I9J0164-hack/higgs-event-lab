# Local Run Outputs

The `outputs/` directory holds machine-generated experiment artifacts: metrics JSON, test predictions, ROC/PR/calibration curves, and result summaries.

## What Is Tracked vs. Ignored

| Item | Tracked by Git? | Notes |
|---|---|---|
| `README.md` | **Yes** | This documentation file |
| `full_colab_results.json` | **Yes** | Full 1M benchmark summary with metrics and artifact list |
| `*_test_predictions.csv` | **Yes** | Held-out test predictions for committed runs |
| `curves/*.json` | **Yes** | ROC, PR, and calibration curve coordinates |
| `experiments.json` | **Yes** | Aggregated experiment records |
| `*/metrics.json` | **Yes** | Per-run `higgs-experiment-v1` metadata |
| `*/test_predictions.csv` | **Yes** | Per-run held-out predictions |
| `model_weights/` | **No** | `.pt`, `.joblib` model binaries — git-ignored, regenerate via Colab notebook |
| Everything else under `outputs/` | **No** | Local runtime cache; not committed |

## Artifact Schema (`higgs-experiment-v1`)

A valid run folder contains:

- **`metrics.json`** — Metadata envelope with schema version, run ID, model architecture, feature group, split seed, training configuration, runtime, and validation/test metrics.
- **`test_predictions.csv`** — Columns: `row_index`, `class_label` ($y \in \{0, 1\}$), `score` ($\in [0.0, 1.0]$).

## Committed Results Summary

The full 1M-event benchmark results are committed under:

- `outputs/full_colab_results.json` — ROC-AUC, PR-AUC, Brier score, accuracy, and training time per model; lists all artifact paths.
- `outputs/logistic_regression_tuned_test_predictions.csv`
- `outputs/xgboost_tuned_test_predictions.csv`
- `outputs/wide_mlp_tuned_test_predictions.csv`
- `outputs/curves/*.json` — Curve coordinates for each run.
- `outputs/experiments.json` and per-run `*/metrics.json` — Mid-semester 250k artifacts.

## Policy

- Commit no full prediction table or large output beyond what is listed above.
- For a final release, export a small curated summary and enough metadata to reproduce the run; obtain team approval before committing a small result file.
- Model weights are regenerated by running `notebooks/03_full/00_full_higgs_colab.ipynb`; they are not committed.
